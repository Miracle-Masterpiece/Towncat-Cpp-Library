**Какой allocator используется после copy assignment?**

```cpp
tca::allocator* alloc0;
tca::allocator* alloc1;

tc::array<int> arr0(5, alloc0);
tc::array<int> arr1(8, alloc1);

arr0 = arr1;
```

При копировании `arr1` в `arr0` аллокатор `arr0` не изменяется. Старые данные `arr0` освобождаются через его текущий аллокатор, после чего для копирования данных `arr1` используется тот же аллокатор.

Таким образом, после операции `arr0` использует `alloc0`, а `arr1` продолжает использовать `alloc1`.

**Какой allocator используется после move assignment?**

```cpp
tca::allocator* alloc0;
tca::allocator* alloc1;

tc::array<int> arr0(5, alloc0);
tc::array<int> arr1(8, alloc1);

arr0 = std::move(arr1);
```

При перемещении `arr1` в `arr0` старые данные `arr0` освобождаются через его текущий аллокатор.

После этого ресурсы `arr1`, включая указатель на используемый им аллокатор, перемещаются в `arr0`.

Таким образом, после операции `arr0` использует тот же экземпляр аллокатора, который ранее использовал `arr1`.

`arr1` остаётся валидным, но находится в неопределённом состоянии.

**Что происходит с allocator при copy constructor?**

```cpp
tca::allocator* alloc0;

tc::array<int> arr0(5, alloc0);
tc::array<int> arr1 = arr0;
```

При копировании `arr0` в `arr1` копируются содержащиеся в `arr0` объекты и указатель на его аллокатор.

Сам объект аллокатора не копируется. `arr1` начинает использовать тот же экземпляр аллокатора, что и `arr0`.

**Что происходит с allocator при move constructor?**

```cpp
tca::allocator* alloc0;

tc::array<int> arr0(5, alloc0);
tc::array<int> arr1 = std::move(arr0);
```

При перемещении все ресурсы `arr0`, включая указатель на используемый им аллокатор, перемещаются в `arr1`.

`arr0` остаётся валидным, но находится в неопределённом состоянии.

**Что гарантируется для moved-from объекта?**

* После перемещения объект остаётся валидным, но находится в неопределённом состоянии.

* Для такого объекта гарантируется возможность корректного уничтожения. Он также может быть присвоен новым значением посредством копирования или перемещения.

**Можно ли копировать `tc::array` с разными allocator?**

* Да.

* Allocator не является частью типа `tc::array`, поэтому контейнеры с разными экземплярами аллокаторов могут быть скопированы друг в друга.

**Можно ли перемещать `tc::array` с разными allocator?**

* Да.

* При перемещении allocator перемещается вместе с ресурсами контейнера.

**Кто освобождает память после операции?**

* Память и ресурсы, принадлежащие `tc::array`, освобождаются самим `tc::array` через текущий аллокатор.

* При copy assignment контейнер продолжает использовать свой исходный аллокатор.

* При move assignment контейнер получает аллокатор вместе с перемещёнными ресурсами.
