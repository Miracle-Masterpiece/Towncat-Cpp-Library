**Что такое Towncat-Cpp-Library?:**
Библиотека общего назначения, целью которой создать единую экосистему над разными модулями с возможностью передавать свои аллокаторы. А так же предоставить собственные абстракции контейнеров, памятью, I/O, многопоточности и других задач.

**Почему она существует?:**
Библиотека изначально создавалась для использования собственных распределителей памяти в C++11, где ещё отсутствует стандартная модель полиморфных распределителей памяти.

В дальнейшем библиотека расширилась другими компонентами. В частности, она предоставляет собственные абстракции для сетевого взаимодействия, ввода-вывода, контейнеров, многопоточности, работы с изображениями и аудио, сжатия данных и других задач.

Одной из целей библиотеки является уменьшение количества различающихся интерфейсов и создание единого набора компонентов, которые можно использовать совместно.

**Какие принципы?:**
Towncat-CPP-Library не является набором обёрток над стандартной библиотекой (За некоторыми исключениями). Она предоставляет собственные абстракции и использует их последовательно во всей библиотеки.

Часть API и концепций библиотеки вдохновлена другими языками и библиотеками. Например, модель потокового ввода-вывода использует идеи декораторов, похожие на подход, используемый в Java.

**Что в ней есть?:**
* Распределители памяти
* Контейнеры
* Языковые утилиты
* Сеть
* Многопоточность
* Математика
* Аудио
* Изображение
* Стектрейс
* Сжатие
* Ввод-вывод
* Traits
* Работа со строками
